# @mnmal-ai/surface-kit

Stateless view primitives (Ink 8 + React 19): `Panel`, cell-width helpers, markdown spans, spinners and sparklines. Colours come from `@mnmal-ai/surface-theme` tones.

Part of [surface](https://github.com/mnmal-ai/surface). Pre-1.0: the module contract may break between minor versions.
